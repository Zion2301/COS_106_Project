Reflection

What these projects taught me

  1. Start with a real problem. Provara exists because booking a barber in Port Harcourt was harder than it should be.
  2. Ship early, then improve based on what users actually do.
  3. Good structure (semantic HTML, reusable CSS, small JavaScript functions) makes code easier to maintain.
  4. Design for phones first, because that is where most of my users are.
